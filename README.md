# ☕ Kalua - Cafe Recipe Manager

カフェ・飲食店向けのレシピ管理・共有プラットフォーム。
オーナーがレシピを作成・管理し、スタッフがそれをスムーズに閲覧・学習するためのモダンなWebアプリケーションです。

### 注意点
アプリは開発中であり、機能が追加される可能性があります。


## ✨ 主な機能

### 📝 レシピ管理 (Owner)
- **リッチな作成機能**: 写真、材料、手順、タグを含む詳細なレシピページを作成できます。
- **カテゴリ整理**: ドラッグ＆ドロップ（予定）でのカテゴリ整理や、タグによるフィルタリングが可能。
- **多彩なビュー**: 効率的な「リスト表示」と、視覚的な「ボード表示（カンバン形式）」を切り替え可能。

### 👩‍🍳 スタッフ支援 (Staff)
- **閲覧専用モード**: 誤操作を防ぐため、スタッフアカウントではレシピの編集・削除ができません。
- **学習チェック**: 「理解しました！（Mark as Understood）」ボタンで、レシピの習熟度をオーナーに報告できます。
- **リアルタイム在庫管理**: 営業中に「Sold Out」スイッチを切り替えることで、ホールの在庫状況を即座に共有できます。

### 🔔 通知センター
- **更新アラート**: 新メニューの追加やレシピの更新があると、サイドバーに未読バッジでお知らせします。
- **スマート通知**: オーナー自身の操作は通知されず、スタッフに必要な情報だけが届くように最適化されています。

### 🔐 権限管理 (RBAC)
- **Owner**: 全権限（レシピ作成・編集・削除、店舗設定）。
- **Staff**: 閲覧、既読アクション、Sold Out切り替えのみ。
- **Guest**: ログインデモ用の制限付きアクセス（自動的にStaff相当として振る舞います）。

## 🛠️ 技術スタック

- **Frontend**: [Next.js 14+](https://nextjs.org) (App Router), TypeScript
- **Styling**: [Tailwind CSS](https://tailwindcss.com), Lucide React (Icons)
- **Backend / DB**: Firebase (Firestore, Authentication, Storage)
- **Drag & Drop**: @dnd-kit/core

## 🚀 開発の始め方

### 前提条件
- Node.js (v18+)
- Firebase プロジェクトの設定

### セットアップ

```bash
# リポジトリのクローン
git clone https://github.com/your-repo/kalua.git

# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いて確認してください。

## 📱 モバイル対応
スマートフォン（iOS / Android）での表示に完全対応しています。キッチンやホールでの立ち仕事でも片手で操作しやすいUI設計を行っています。
